# BarberPlay 💈

> Plataforma SaaS de Gestión Inteligente y Turnero para Smart TV especializada en Barberías, desarrollada por **Appzplay**.
> Despliegue en producción: [https://barber.appzplay.online](https://barber.appzplay.online)

## Características Principales

- 📺 **Turnero en Vivo para Smart TV**: Pantalla optimizada para televisores en sala de espera con anuncio de turnos por voz y campanilla.
- 💈 **Multi-Barbero & Control de Sillas**: Cada barbero atiende en su propia silla con acceso desde celular en `/barbero`.
- 💵 **Liquidación de Comisiones**: Configuración de porcentajes (50%, 60%, etc.) y liquidación diaria automática.
- 🛍️ **Venta de Productos & Barber Shop**: Control de stock de ceras, pomadas, navajas y aceites con registro de caja.
- 💬 **WhatsApp & Cero Ausencias**: Enlace directo para que clientes reserven o tomen turno en vivo.
- ⭐ **Prueba Gratuita PRO de 7 Días**: Nuevas barberías disfrutan de todas las herramientas avanzadas durante 7 días.

## Pila Tecnológica

- **Framework**: Next.js 16 (App Router) + React 19
- **Base de Datos**: PostgreSQL + Prisma ORM
- **Estilos**: Tailwind CSS 4
- **Despliegue**: Docker + Coolify en `https://barber.appzplay.online`
